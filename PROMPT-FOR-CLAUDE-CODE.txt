משימה 1 — לקמט ולדחוף
═══════════════════════════════════════════════════════════════

1. הרץ `git status --short` והצג לי מה עומד להישמר.

2. הרץ את הבדיקות לפני הקומיט. כולן אמורות לעבור:
     npm run typecheck
     npm run lint
     npm test
   אם משהו נכשל — עצור, הראה לי את השגיאה, ואל תקמט.
   (`npm run build` ידרוש גישה לרשת עבור Google Fonts; אם הוא נכשל רק על
    הורדת הפונט Poppins — זה בסדר, המשך.)

3. צור ענף חדש: git checkout -b feature/agent-portal

4. לפני ה-add — ודא ש-.gitignore באמת מכסה את קובץ הסביבה, כדי שהבעיה
   לא תיווצר מלכתחילה ולא רק תיתפס אחרי שהיא כבר קרתה:
     git check-ignore -v .env.local
   הפקודה אמורה להדפיס את השורה `.env*.local` מתוך .gitignore. אם היא לא
   מדפיסה כלום — עצור והודע לי לפני שאתה מוסיף משהו.

5. הוסף הכל, ואז הוצא שלושה קבצים שאינם שייכים למאגר:
     git add -A
     git reset -- agent-portal.patch src.zip tsconfig.tsbuildinfo

6. בדיקת בטיחות שנייה, אחרי ה-add. הרץ:
     git diff --cached --name-only
   אם מופיע שם .env.local או כל קובץ .env אחר — עצור מיד, בטל את הכל
   (git reset), והודע לי. הקובץ מכיל SUPABASE_SERVICE_ROLE_KEY שעוקף כל
   הרשאה במסד, ודליפה שלו ל-GitHub אינה הפיכה.

7. קמט עם ההודעה המוכנה שכבר יושבת בשורש:
     git commit -F COMMIT-MESSAGE-agent-portal.txt

8. דחוף: git push -u origin feature/agent-portal

9. הצג לי את git log --oneline -1 ואת ה-URL של הענף ב-GitHub.

אסור: אל תעשה force push, אל תשכתב היסטוריה, אל תיגע בענף main, ואל תמחק
קבצים. אם משהו לא מסתדר — עצור ותשאל אותי.
